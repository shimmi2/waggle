O aplikaci

Tahle stránka je statický soubor page_about.html, servírovaný zkratkou page_*: dispatcher ho jen prožene output bufferem a pošle jako příkaz html. Žádný switch, žádná logika.

Aplikace /app a /app2 mají totožné endpointy — liší se jen markup fragmentů. Framework, protokol i session jsou stejné.
